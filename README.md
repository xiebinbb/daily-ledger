# Daily Ledger

一个轻盈、私密的个人记账单页应用，采用 Apple 风格的留白、层次和微交互设计。

## 功能

- 按天查看账单，支持前后日期切换
- 支出 / 收入录入，分类、备注和日期均可编辑
- 本地浏览器存储，刷新后数据仍然保留
- 今日支出、收入、本月支出、日均和预算进度统计
- 自动生成当日账单整理和最大支出摘要
- 本月分类花费概览
- 支持浏览器系统通知

## 本地运行

这是一个无构建依赖的静态站点。直接打开 `index.html` 即可预览；推荐使用任意静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 数据与推送说明

账单数据仅保存在当前浏览器的 `localStorage` 中，不会上传到服务器。GitHub Pages 是静态托管，因此“每日推送”使用浏览器 Notification API：用户开启权限后，在页面打开时可以收到系统提醒。若需要页面关闭后仍能跨设备定时推送，需要接入后端数据库、定时任务和推送服务。
